# Middle Class Commander App

## What is Middle Class Commander?

It's a Magic: The Gathering format, of course.

I'll detail out the rules later.

## What is this app?

I need a web application to share:
- The rules and details of the format
- Tools to make deckbuilding in the format easier
  - A deck analyzer that tells you if you included any banned cards

I'm going to build the backend with Express as a portfolio piece, and because I want to not get banned by slamming the Scryfall API too hard.

I'm going to let Codex build the frontend because I'm not focusing on design or frontend right now.
